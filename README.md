# ShieldCover — Insurance Company Landing Page

A trust-first insurance landing page featuring a live quote calculator, product cards, FAQ accordion, and client reviews. The quote widget calculates a real price client-side based on age and coverage type.

## Features

- **Live quote calculator** — age × coverage type formula → instant price update (no API needed)
- **Product cards** — auto, home, health, travel insurance with coverage highlights
- **FAQ accordion** — expand/collapse with smooth animation
- **Client reviews** — star ratings and verified testimonials
- **Contact form** — name, email, phone, query type → success state
- **Trust badges** — regulatory logos, years established, claims paid
- **Mobile navigation** — hamburger menu

## Tech Stack

- [Next.js 16](https://nextjs.org/) — App Router
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) — icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
